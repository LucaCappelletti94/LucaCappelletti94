I work on Rust, SQL, and machine learning at the University of Fribourg with the [Earth Metabolome Initiative](https://github.com/earth-metabolome-initiative), and am affiliated with [Lawrence Berkeley National Laboratory](https://phonebook.lbl.gov/?search=LucaCappelletti). I am one of the main contributors to [Diesel](https://github.com/diesel-rs/diesel), [sqlparser-rs](https://github.com/apache/datafusion-sqlparser-rs), and [bhtsne](https://github.com/frjnn/bhtsne).

I am building [connetto-rs](https://github.com/LucaCappelletti94/connetto-rs), a local-first Rust stack in which native and browser applications work against local SQLite replicas while PostgreSQL remains authoritative. It brings together offline operation, optimistic writes, live query subscriptions, file synchronization, and authorization-aware change delivery, without a network round trip for every interaction.

I am the main contributor to [OpenScientist](https://github.com/openscientist-io/openscientist), an autonomous hypothesis-testing agent for scientific data. I built its agent and model-provider layers, air-gapped execution mode, and various harnesses and providers integration.

During my PhD, I was the main contributor to [GRAPE](https://github.com/AnacletoLAB/grape), [ensmallen](https://github.com/AnacletoLAB/ensmallen), and [embiggen](https://github.com/monarch-initiative/embiggen), a Rust/Python ecosystem for large-scale graph processing and representation learning.

My work in ML spans contributions to the [Burn](https://github.com/tracel-ai/burn) ecosystem, GPU kernels, quantized matrix multiplication, FFTs, atomics, and compiler correctness. I also investigate low-level failures, including isolating and reporting a [CUDA compiler miscompilation](https://github.com/LucaCappelletti94/ptxas-uniform-counter-miscompile) that silently produces incorrect results under optimization. I also develop [geometric-traits](https://github.com/earth-metabolome-initiative/geometric-traits), a Rust library for graph algorithms and combinatorial optimization, such as maximum matching, minimum-cost assignment, planarity testing, subgraph isomorphism, community detection, and graph layout.

Within the Earth Metabolome Initiative, I develop Rust libraries for cheminformatics and mass spectrometry: [smiles-rs](https://github.com/earth-metabolome-initiative/smiles-rs), [smarts-rs](https://github.com/earth-metabolome-initiative/smarts-rs), [molecular-formulas](https://github.com/earth-metabolome-initiative/molecular-formulas), [elements-rs](https://github.com/earth-metabolome-initiative/elements-rs), [mascot-rs](https://github.com/earth-metabolome-initiative/mascot-rs), and [npclassifier-rs](https://github.com/earth-metabolome-initiative/npclassifier-rs). I have also contributed spectral-similarity algorithms to [matchms](https://github.com/matchms/matchms).
