I work on Rust, SQL, and machine learning at the University of Fribourg with the [Earth Metabolome Initiative](https://github.com/earth-metabolome-initiative), am affiliated with [Lawrence Berkeley National Laboratory](https://phonebook.lbl.gov/?search=LucaCappelletti), and am an [Apache DataFusion committer](https://people.apache.org/phonebook.html?uid=lucacappelletti). I am one of the main contributors to [Diesel](https://github.com/diesel-rs/diesel), [sqlparser-rs](https://github.com/apache/datafusion-sqlparser-rs), and [bhtsne](https://github.com/frjnn/bhtsne).

On the GPU side, I contribute to the [Burn](https://github.com/tracel-ai/burn) ecosystem, including quantized matrix multiplication, FFTs, and atomics. While working on compiler correctness, I isolated a [ptxas miscompilation](https://github.com/LucaCappelletti94/ptxas-uniform-counter-miscompile) that silently produces wrong results at any non-zero optimization.

Within the Earth Metabolome Initiative, I build Rust libraries for cheminformatics and mass spectrometry, among them [smiles-rs](https://github.com/earth-metabolome-initiative/smiles-rs), [molecular-formulas](https://github.com/earth-metabolome-initiative/molecular-formulas), and [mascot-rs](https://github.com/earth-metabolome-initiative/mascot-rs). I have contributed spectral similarity algorithms to [matchms](https://github.com/matchms/matchms). I also develop [geometric-traits](https://github.com/earth-metabolome-initiative/geometric-traits), a library for graph algorithms and combinatorial optimization such as maximum matching, minimum cost assignment, planarity testing, and subgraph isomorphism.

During my PhD I was the main contributor to [GRAPE](https://github.com/AnacletoLAB/grape), [ensmallen](https://github.com/AnacletoLAB/ensmallen), and [embiggen](https://github.com/monarch-initiative/embiggen), a Rust and Python ecosystem for large scale graph processing and representation learning.

I am building [connetto-rs](https://github.com/LucaCappelletti94/connetto-rs), a local-first Rust stack where native and browser applications work against local SQLite replicas while PostgreSQL remains authoritative. It provides offline operation, live query subscriptions, and authorization-aware change delivery without a network round trip per interaction, across server, native client, and WASM client crates. I am also the main contributor to [OpenScientist](https://github.com/openscientist-io/openscientist), an autonomous hypothesis testing agent for scientific data, where I built the agent layer, the model provider integrations, and the air-gapped execution mode.
